# 四个课程资料目录的用途与方法复核

核对日期：2026-10-27。对象为DM_2026_Dataset下的Cluster、thyroid、FinanceQA、Image_Anomaly_Detection。用户是成员A，负责任务二，暂不做可选拓展。

## 结论

**任务二直接使用Image_Anomaly_Detection。现有实现的数据来源、预测目标、标签对齐和划分边界与课程材料相符，没有需要整体删除重写的任务方向错误。**

Cluster对应任务一，thyroid对应任务四，FinanceQA对应可选财务问答Agent。不能因为四个目录同时下载，就把所有样本或标签混入图片异常检测。

局部近邻对拉链召回较低，属于需要如实讨论的方法局限。保留三条预定路线及失败结果，不在看过测试后修改阈值或拼接最优方法以掩盖失败。

## 1 Cluster

有效文件为600张PNG和1个cluster_labels.json。实际路径为Cluster/Cluster/dataset/。标签以文件名映射物体类别：bottle、cable、leather、pill、tile、transistor，每类100张。

已检查600张图片的模式、尺寸、全部标签路径，并查看每类代表图。标签是物体类别，不是任务二的正常/异常；这六类与hazelnut、zipper不重合。

可参考成员B的图像读取、HOG和可视化经验；当前实现没有使用这些图片、聚类标签或聚类模型。任务一的聚类准确率不代表任务二效果。

## 2 thyroid

有效文件只有thyroid/thyroid/train-set.csv和test-set.csv：

- 训练1839条，6个数值特征，无标签列；作业说明明确训练样本均正常。
- 测试1933条，6个特征加label；正常1839条、患病94条，原标签写为0.0/1.0。
- 已读取全部3772条记录并检查数值有效性，六维特征均为有限数值。

这是任务四数据。可借鉴“正常参考—距离评分—独立校准—测试评价”的实现结构，但六维医疗特征未用于图片训练。

任务四只给正常训练样本，不能机械地当作任务二的唯一设置。任务二明确另给每类50张异常训练图，因此可以使用这些训练标签做有监督对照，并说明区别。

## 3 FinanceQA

排除macOS附带项后有27个有效文件，包含SQLite、9份年报HTML、37道训练题、19道测试题、输入输出协议、基础Agent提示词和独立评测材料。数据库有6家公司、86306条financial_facts、5889条filings元数据。

已阅读README.md、TASK.md、schema.md、business_rules.md、年报目录、输入输出JSON协议及基础提示词；检查公司/题目划分，以只读连接核对数据库结构和行数，并检查9份年报文件和标题。没有逐题生成财务答案，也没有解析测试参考答案用于设计方法。评测材料仅作文件清单和哈希记录。

README和TASK明确这是需自主查询、检索、计算并记录工具日志的可复用Agent任务，不是图像异常检测的特征或训练素材。用户暂不做可选项，因此不进入当前实现。

另发现README引用的“数据使用与作业完成流程.md”在当前包中不存在，部分评测说明文件名有编码异常。本次未修改这些课程原文件。

匹配必须使用hazelnut/test/001.png等完整相对路径，不能只按001.png匹配。已检查全部文件和解码像素哈希，未发现完全重复图片；不能据此证明物体实例独立。

## 5 对已有实现的判断

| 项目 | 现有行为 | 判断 |
| --- | --- | --- |
| 数据源 | 只读取任务二原图 | 相符 |
| 目标 | 每个物体类别内预测good/bad | 相符 |
| 类别覆盖 | 两类分别训练与评价 | 相符 |
| 标签 | 训练用子目录，测试用完整JSON路径 | 相符 |
| 图像模式 | 明确统一RGB/灰度 | 可复现，颜色损失列为局限 |
| 正常学习 | 两个近邻只拟合正常图 | 合理设定，不声称是唯一允许设置 |
| 异常训练图 | SVM用40张拟合、10张验证 | 有监督对照，明确额外标签使用 |
| 模型与阈值 | 内部验证，测试前冻结 | 相符 |
| 评价 | 按类指标、混淆计数、曲线及误报漏报 | 覆盖2.3 |
| 定位 | 只有块级定性热力图 | 与未提供像素掩码相符 |
| 其他资料 | 未混入数据，未实施可选项 | 符合范围 |

因此保留实现和真实证据，补齐资料说明与运行文档；“方向错误则删除重写”的条件没有触发。
